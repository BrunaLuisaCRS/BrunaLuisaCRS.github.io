# Portfólio — Bruna Luísa

Site estático de portfólio em HTML, CSS e JavaScript, com visual criativo e alternância entre português e inglês.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `style.css`: visual responsivo.
- `script.js`: alternância de idioma.
- `assets/`: pasta para imagens opcionais.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `BrunaLuisaCRS.github.io` (confirme a grafia exata do seu usuário).
2. Envie todos os arquivos desta pasta para a raiz da branch `main`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação e use a URL mostrada em Settings → Pages.

Documentação oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
